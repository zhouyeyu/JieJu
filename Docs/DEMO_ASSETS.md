# 公开演示素材规范

README、Release 和问题复现只能使用以下素材：

- 自行编写并明确允许公开的短文；
- 公有领域作品，并记录来源与公有领域依据；
- 采用允许再分发许可证的测试文档，并保留作者和许可证信息；
- 程序生成的最小 PDF / EPUB fixture。

截图前应隐藏用户名、绝对文件路径、API Key、私人批注、最近文件列表和无权公开的正文。模型讲解截图只保留展示功能所需的短句，并注明 AI 输出可能有误。

建议首批公开素材覆盖：

1. PDF 选句与流式语法讲解；
2. EPUB 主题、行距和边距预览；
3. 日语注音开关；
4. 单词加入生词本和复习卡片；
5. 本地 Ollama / 云端 Provider 的隐私提示。

当前仓库中的个人测试书籍不得用于公开截图、fixture、Release 或 Issue 附件。
