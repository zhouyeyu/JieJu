# Windows 解释与注音对齐清单

事实基线为 macOS `ReaderView`、`ReaderViewModel`、`AppSettings`、`JieJuLanguage` 和
`EPUBWebReaderView`。只有源码、自动测试和 Windows 真机验收全部通过后才勾选。

## 已对齐

- [x] `WEXP-001` EPUB 选区、有限前后文、Ruby 排除、取消与错误状态
- [x] `WEXP-002` Ollama 快速解句、中文输出约束、结构校验、一次修复和越界条目清洗
- [x] `WEXP-003` 词语/表达/句子/段落分类、人工切换和保守英文边界建议
- [x] `WEXP-004` 独立词语解释、收藏及学习记录
- [x] `WJA-001` 显示或隐藏 EPUB 原书已有 Ruby，选区不包含 `rt/rp`
- [x] `WJA-101` Windows 本地日语形态分析：分词、读音、原形、词性、活用和选区边界
- [x] `WJA-102` 对无原书 Ruby 的日语 EPUB 自动注音；跳过已有 Ruby/脚本/样式并防止多音误注

## 待对齐

- [x] `WEXP-101` 翻译、主干、语法和重点表达在 Ollama 生成时分区渐进显示
- [x] `WEXP-102` 深入解析：句子类型、句型、成分、修饰关系、从句、深度语法和整句理解
- [x] `WEXP-103` 侧边栏/弹窗两种解释方式及持久化，切换时不丢阅读位置和选区
- [ ] `WEXP-104` OpenAI-compatible 云端 Provider、SSE、连接检查、隐私提示和 Credential Manager
- [ ] `WJA-103` 解释面板中的日语选区、词语和深入解析使用本地词典 Ruby；模型读音只作参考

## 实施顺序

1. `WEXP-101` 渐进展示，复用当前 Ollama NDJSON 流。
2. `WEXP-102` 深入解析，继续使用共享 v1 DTO；日语本地语法部分等 `WJA-101` 后补齐。
3. `WEXP-103` 解释显示方式。
4. `WJA-101`～`WJA-103` 本地形态分析与自动注音。
5. `WEXP-104` 云端 Provider；该步骤会涉及真实外网，单独记录流量与凭据边界。

## 验收原则

- 本地模式只访问 `127.0.0.1`，不产生外网或 VPN 流量。
- 读音、原形和词性不能以小模型输出作为真值。
- 中文解释没有中文、选区引用串入上下文或结构不合法时不能保存。
- Windows 不具备的能力继续显示为待完成，不以按钮或演示数据代替实现。
