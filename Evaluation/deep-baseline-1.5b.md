# 深度句法 1.5B 基线

- 日期：2026-09-02
- 设备：Apple Silicon Mac（本地 Ollama）
- 模型：`qwen2.5:1.5b-instruct`
- 数据集：`deep-syntax-smoke.jsonl`，12 句
- 严格结构校验成功：6/12（50%）
- 平均端到端耗时：20.1 秒/句

## 分类结果

| 分类 | 成功/总数 |
| --- | ---: |
| 简单句 | 1/2 |
| 复合句 | 2/2 |
| 非谓语 | 2/2 |
| 倒装 | 1/2 |
| 省略 | 0/2 |
| 指代 | 0/2 |

失败主要来自：模型把语法标签或整段结构说明写入必须逐字摘自目标句的字段、字段类型不符合
Schema，以及擅自改写原文（例如把 `was` 改为 `is`）。严格校验成功的结果也不等于语法正确：
抽查发现普通状语被标成从句、非谓语结构被归为普通简单句、倒装句被归为简单句等误判。

## 结论

1.5B 可以演示深度解析交互，但当前质量不适合作为可靠语法教学结论。保持快速解句与深入解析
分离，并将深入解析标为实验性。下一步使用同一数据集对照 3B；重点比较严格成功率、句型与
成分人工正确率，以及 Apple Silicon 上的延迟。只有质量提升明显且延迟可接受时才推荐 3B。
